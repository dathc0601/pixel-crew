## Not shipped

### Donarg "Office Interior Tileset (16x16)" (paid, not redistributable)

`apps/web/src/components/office/sprites/assetLoader.ts` contains sprite
coordinates for this tileset (https://donarg.itch.io/officetileset). The
image itself is **not** in this repository and must never be distributed,
even edited. The loader only runs in local development when you own the
tileset, place it in `apps/web/public/Office Tileset/` (gitignored) and set
`NEXT_PUBLIC_BYO_TILESET=1`. Production builds compile the loader out, and
the web build deletes `out/Office Tileset/` if present. Without it, furniture
uses built-in fallback sprites.

### Themed office backgrounds (unknown provenance)

Twelve themed backgrounds inherited from upstream have no recorded source or
license. They are quarantined in `apps/web/assets-quarantine/` and are not
part of any build. See `apps/web/assets-quarantine/README.md`.
